# Pokémon 4ever — Traducción al castellano

**English speakers:** [read this README in English](#english).

Traducción no oficial al castellano (España) de **Pokémon 4ever**, el hack alemán de **Pokémon Oro** del **POKE4EVER-Team**, con la edición de **HFD (Meowth Hacks)**: Johto con historia, personajes y Pokémon cambiados (WOLLI, ICEPIL, TERROR, MEWTERROR, TIAMAT…).

> Este repositorio solo contiene el parche de la traducción.
> **No incluye ninguna ROM.** Necesitas tu propia copia de Pokémon Gold (USA, Europe).

---

## Cómo jugar

1. Consigue una ROM de **Pokémon - Gold Version (USA, Europe) (SGB Enhanced)**.
   - CRC32: `6BDE3C3E`
2. Aplica el parche [`Pokemon4ever_ES.bps`](https://github.com/SeCaVa/Pokemon4ever-TraduccionCastellano/releases/latest)
   con el [parcheador web](https://secava.github.io/secava-parcheador/), con
   [Rom Patcher JS](https://www.marcrobledo.com/RomPatcher.js/) o con Floating IPS (Flips).
3. El resultado es una ROM de Game Boy Color con **CRC32 `05AA2D42`**. Juega con cualquier emulador de GBC.

Versión actual: **v0.13**. SHA-256 del parche: `69fe89b1793469009ca5f454e75148bdca425592504b1c115a5124727ca8c294`.

El parche se aplica **directamente a Pokémon Gold USA**: no hace falta conseguir el hack alemán, porque ya lo incluye.

---

## Qué está traducido

- **Todos los diálogos** del juego y los combates de entrenadores.
- **Menús y combate**: menú START, ficha de entrenador, mochila, Pokédex, Pokégear, opciones y mensajes de combate.
- **Nombres**: Pokémon, movimientos, objetos, tipos, clases de entrenador y lugares. Donde existe un nombre o un
  texto oficial, se usa el de **Pokémon Edición Oro en español**.
- Gráficos con texto: mochila, ficha de entrenador, letreros y pantalla de título.

### Errores
Si encuentras algo en alemán, un texto que se sale del cuadro o una errata, rellena el
[formulario de fallos](https://github.com/SeCaVa/Pokemon4ever-TraduccionCastellano/issues/new?template=fallo.yml).
